# README illustrations

[`touch-guide.en.svg`](touch-guide.en.svg) and
[`touch-guide.zh-CN.svg`](touch-guide.zh-CN.svg) are original schematic gesture
illustrations for the RimTouch documentation. They show colony-map pan/zoom and
world-view twist. They are not game screenshots and contain no game or preview
artwork.

These two SVG files are distributed under **GPL-3.0-or-later**, the same license
as the program; see [LICENSE](../../LICENSE). English and Simplified Chinese
versions share the same drawing and differ only in text and font preferences.
Keep their geometry and meaning synchronized when editing.
